# ChessGame

Небольшие шахматы против компьютера на C++20 и Raylib. Белыми управляет игрок, чёрными — движок Minimax с Alpha-Beta pruning.

## Сборка

Из PowerShell в каталоге проекта:

```powershell
cmake -S . -B build -G "MinGW Makefiles"
cmake --build build -j1
ctest --test-dir build --output-on-failure
```

CMake использует статическую Raylib; при сборке шрифт и его лицензия копируются рядом с исполняемым файлом.

## Портативная сборка

Raylib линкуется статически: отдельная `raylib.dll` не нужна, её код включается в исполняемый файл. На Windows с MinGW используется готовый статический `libraylib.a` из `../Libraries/raylib_files`, а MinGW C++ runtime также линкуется статически. На MSVC, Linux и macOS CMake собирает статический Raylib 6.0 в `build/_deps`; для первого configure на этих платформах нужен доступ к GitHub. Файлы в `Codex/Libraries/raylib_files` CMake не изменяет.

Нужна отдельная нативная сборка для каждой ОС и архитектуры. На Windows рядом с `ChessGame.exe` должна находиться скопированная CMake папка `resources/` со шрифтом; системные DLL Windows (например, `KERNEL32.dll`) остаются частью ОС.

Движок использует небольшую офлайн-книгу распространённых дебютных ответов и передаёт историю партии в поиск. Вне книги ход выбирается итеративным Minimax с Alpha-Beta pruning, таблицей транспозиций, quiescence-поиском и эвристиками порядка ходов. Глубина настраивается в `include/config/engine_settings.h`; окно остаётся отзывчивым, пока движок думает.

## Управление

- Нажмите «Играть», затем щёлкните по белой фигуре и по подсвеченной клетке назначения.
- `Esc` возвращает в меню.
- После завершения партии щёлкните, чтобы вернуться в меню.

В `include/config/` находятся настройки окна, цветов, ресурсов и подписей меню. Для шахматных Unicode-фигур используется DejaVu Sans из `resources/fonts/`; лицензия сохранена рядом со шрифтом. Если файл шрифта недоступен, renderer показывает буквенные обозначения фигур.
